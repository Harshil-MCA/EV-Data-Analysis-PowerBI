# Electric Vehicle Data Analysis using Power BI

## Project Overview
This project analyzes electric vehicle (EV) registration data from Washington State using Python, Pandas, and Microsoft Power BI. The dashboard helps identify trends in EV registrations, popular manufacturers, vehicle models, geographical distribution, electric range, and CAFV eligibility.

## Dataset
- **Total records:** 177,866
- **Columns:** 17
- **Manufacturers:** 40
- **Vehicle models:** 139
- **Location:** Washington State, USA

## Tools and Technologies
- Python
- Pandas
- Jupyter Notebook
- Microsoft Power BI
- Data visualization and exploratory data analysis (EDA)

## Dashboard Features
- EV registrations by model year
- Battery Electric Vehicle (BEV) and Plug-in Hybrid Electric Vehicle (PHEV) distribution
- CAFV eligibility analysis
- EV registrations by state and city
- Top 10 EV models and manufacturers
- Electric utility analysis
- Average electric range by vehicle type and model year
- Manufacturer range comparison
- Base MSRP analysis

## Key Findings
- BEVs account for 78.27% of the records.
- PHEVs account for 21.73% of the records.
- Tesla represents approximately 44.8% of the records.
- Washington accounts for approximately 99.8% of the records.
- A significant proportion of electric range and eligibility values are unknown or unavailable.

## Data Limitations
Some electric range and MSRP values are recorded as zero, and some eligibility values are unknown. These values may affect averages and should be handled carefully when interpreting the results.
